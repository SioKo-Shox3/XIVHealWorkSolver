# XIVHealWorkSolver

**所持スキル定義（データ）から自動で軽減・ヒールワークを最適化する汎用 FF14 タイムラインソルバー**。

ジョブ固有のロジックをソルバーにハードコードせず、すべてのスキルを汎用プリミティブ（リキャスト・チャージ・効果時間・物理/魔法/全軽減・バリア・戻し・リソース収支・Weave 枠コスト）として定義する設計です。大型パッチや将来のジョブ改修でも、スキル定義 YAML を差し替えるだけでそのまま動作します。

## 主な機能
1. **FFLogs v2 連携 (`xiv-healwork fetch-report` / `learn-partner`)**
   - レポートから敵の攻撃タイムライン（着弾時刻・属性・生ダメージ）を自動抽出（ローカル JSON キャッシュ付き）
   - **固定モード**（特定メンバーのログから癖を学習）と **野良モード**（複数クリアログから標準分布を学習）の両方に対応
   - 自分の過去ログから時間帯ごとの空き Weave 枠を推定するユーティリティも搭載
2. **汎用 CP-SAT 最適化ソルバー (`xiv-healwork optimize` / `replan`)**
   - リキャスト・チャージ・重複グループ・リソース収支（MP / 固有スタック等）を厳密制約として最適化
   - **装備・サブステ反映**：タンクの不屈（常時パッシブ軽減）、ヒーラーの信仰（MP自然回復）と GCD 速度由来の攻撃 MP 消費、回復倍率、**蘇生用 MP 温存ライン（`planned_raise_reserve`）** を組み込み済み
   - 対数線形化による乗算軽減計算と、効果時間内の複数着弾カバー（早炊き最適化）に対応
   - 自分の **GCD 秒数・2分バースト占有・移動詠唱ペナルティ** に基づく **Weave スロット制約** を考慮
   - **リアルタイム再計画 (`xiv-healwork replan`)**：蘇生やスキルズレ発生時の「現在時刻・残MP・リキャスト残り・現在HP」から残りタイムラインを数十ミリ秒で即座に引き直し
   - プリセット切替：`balanced`（標準）/ `dps_greedy`（火力寄り）/ `safe`（安全重視）/ `solo_carry`（相方非依存）
3. **ロバスト性シミュレーション (`xiv-healwork simulate` / Google Colab 実行対応)**
   - 相方軽減の抜け・タイミングズレ・ダメージ乱数ブレを数千通りモンテカルロ検証し、事故率・最低残 HP を可視化
4. **タイムラインシート出力**
   - 最適化されたヒールワーク・軽減表を **Markdown / CSV / JSON** として出力

## セットアップ
```powershell
uv sync --extra dev
copy .env.example .env
# .env に FFLogs の FFLOGS_CLIENT_ID / FFLOGS_CLIENT_SECRET を記入
```

## クイックデモ（FFLogs 認証前でも動作確認可能）
```powershell
uv run xiv-healwork demo
```
