# XIVHealWorkSolver 設計監査 & 改修ロードマップ

零式 MVP から絶（Ultimate）対応までを見据えた戦闘モデル・FFLogs 取り込み・最適化・強化学習のギャップ整理と改修計画。

---

## 再現確認された優先修正事項（現行実装の落とし穴）

1. **被弾間の HP・バリア・回復の持ち越し欠如（CP-SAT vs 時系列再生の不一致）**
   - 現行 `solver.py` は各イベントを「最大 HP スタート」で独立評価するため、2 秒後・4 秒後の連続全体攻撃（各 60,000 / 最大 HP 100,000）を `OPTIMAL`（残 HP 40,000 → 40,000）と誤判定する（実再生では 4 秒で死亡）。
2. **0.5 秒固定刻みによる GCD の丸め（SS 差の消失）**
   - 現行 `rl/env.py` は `dt=0.5s` の固定ステップで `gcd_timer` を切り上げるため、`GCD 2.50 / 2.40 / 2.31s` がすべて 60 秒間 24 回に丸められ、装備の SS / GCD の違いと MP 消費差が反映されない。

## P0: 零式 MVP に必須

### P0-1. 共通の実時刻バトル再生エンジン（Single Source of Truth）
- CP-SAT 計画の検証と RL 環境で **完全に同一の戦闘ルール・実時刻イベント駆動エンジン** を共有する。
- **実時刻（連続時刻）処理**：`0.5s` 固定刻みを廃止し、次の判断可能時刻・GCD 完了・詠唱完了・着弾・3 秒サーバーティック・AA・バフ期限のうち直近イベントへ正確に進める。
- **状態持ち越し**：対象別（Party / MT / ST）の実残 HP・残盾（発生源・競合群・期限・消費順）・進行中 HoT/DoT を被弾間で厳密に引き継ぐ。

### P0-2. ダウンタイム（殴れない時間）の厳密化
- 敵ターゲット可否・味方行動可否・履行ダメージ・資源発生条件を分離。
- 履行中 / 殴れない時間は：
  - ボス対象デバフ（リプライザル・牽制・アドル等）を使用不可にマスク。
  - 攻撃フィラーの MP 消費を停止し、復帰初撃の攻撃 GCD を遅らせない事前バリア仕込みを **DPS ロス 0** として扱う。
  - 攻撃命中依存の回復・ゲージ（カルディア・オウス等）は停止させ、自然時間経過リソース・リキャスト・MP ティックのみ進行させる。

### P0-3. 判定（スナップショット）・着弾・周期効果の分離
- 技ごとに「詠唱完了 / 判定（スナップショット） / 着弾 / ステータス付与」のタイミングを分離。
- **DoT スナップショット**：DoT 付与時点の軽減倍率を DoT インスタンスに固定保持し、後掛け軽減で既存 DoT が弱まらないようにする。
- 多段連打の各段判定、および各 DoT ティックでのバリア消費を正確に再生する。

### P0-4. FFLogs 取り込みの精密化 ＆ 学習データ選別フィルタ
- **精密抽出**：
  - `damage` と `calculateddamage` の重複照合、DoT ティック・AA の別系列保持、MT/ST の個別識別、フェーズ到達 pull のみを分母にした相方行動確率計算。
- **学習データ選別フィルタ（相方丸投げ・外れ値ログの自動除外）**：
  - 単体 rDPS 上位の無差別取得を禁止し、**ヒーラー2名合算 rDPS（Combined Healer DPS）** を評価指標に採用。
  - **有効回復シェア（Effective Healing Share）フィルタ**：片方にヒールが極端に偏っているログ（相方丸投げ / Chad-healing）を除外（例：35%〜65% 範囲を採用）。
  - **PT 軽減稼働率フィルタ**：主要パーティ軽減を極端にサボっているログを除外。
  - **デス数・討伐時間フィルタ**：基本教師データは `deaths == 0` かつ標準討伐時間レンジ（中央値 ±30s、極端なスピードキル除外）。事故リカバリ学習用は `deaths == 1〜2` を別バケット管理。

### P0-5. MP・GCD・詠唱・Weave 枠の正確な会計
- ルーシッドドリームを常時平均化せず、実際のリキャスト・効果時間内の 3 秒ティックで処理。
- 回復 GCD で置換した分の攻撃フィラー MP を二重引きしない。
- 詠唱開始〜完了までの占有時間・着効時刻・硬直（アニメーションロック）を正確に管理。

### P0-6. MT / ST 個別管理とバリア競合ルール
- プレイヤー本人 ID と現在ヘイト 1 位（MT / ST）を分離し、タンクスイッチ後の AA・強攻撃・相方タンク自身の防御バフを正確に各タンクへ配分。
- バリアに `stack_group` / 上書き条件 / 消費順を持たせ、競合するバリアと併存するバリアを区別。

### P0 受入基準（4 シナリオで CP-SAT 再生と RL 環境が完全一致）
1. 連続全体攻撃（2 秒・4 秒の連打で HP 持ち越し・死亡/戻し判定が一致）
2. 履行ダウンタイム中の事前バリア仕込み（DPS ロス 0）→ 復帰初撃着弾
3. DoT 付与の直前軽減 vs 直後軽減（スナップショット差の一致）
4. タンクスイッチ直後の AA 切替と単体ケア

## P1: 絶（Ultimate）＆ 高精度 RL チューニングに必須

1. **無敵受け・特殊ダメージ・HP 戻し**
   - 割合ダメージ・HP 1 残し・盾/軽減/無敵貫通フラグ。
   - タンク 4 種の無敵仕様（無効 / HP 下限 1 / 致死発動＋最大 HP 相当回復＋デッドリバース / 発動時 HP 50% 低下＋無効）と、無敵明け初撃 AA までの戻し判定。
2. **回復効果 UP バフ・多段バリア**
   - 与回復 UP / 被回復 UP、魔法限定 vs アビ含む、次の 1 回 vs 時間内、回復量由来バリア vs 独立バリア、多段バリア（破壊・再付与・残段終了時回復）を汎用効果データとして表現。
3. **移動区間・滑り打ち・無詠唱化・蘇生・フェーズ移行**
   - 詠唱区間と移動区間の重複判定、末尾の滑り打ち許容窓、迅速魔（次の 1 回無詠唱）・詠唱短縮バフ、それに向けたスキル温存。
   - 実死亡 → 蘇生詠唱・受諾 → 復帰 HP/MP・蘇生無敵・行動による無敵解除・衰弱。
   - フェーズ移行ごとの経過秒・操作不能時間・解除バフ・敵交代。
4. **相方モデルと RL 設計の改善**
   - 行動 0（待機）と攻撃フィラー GCD を分離。
   - 観測に AA・残 HoT/DoT・盾期限・全チャージ・任意名リソースを追加し、Value Head にもスキル・マスク情報を入力。
   - 経過秒ベースの時間割引 $\gamma^{\Delta t}$ に変更（120 秒先の大技に向けた温存を正しく評価可能に）。
   - 相方あり / 遅延 / 不発の複数シナリオで検証し、不発時の代替手を提示。

## P2: 発展（FFLogs 模倣学習 ＆ 自分の装備特化チューニング）

- **FFLogs からの行動模倣（BC）事前学習 → 自分の装備（GCD / 信仰 / 不屈 / 意思力）特化 PPO 微調整**
  - 同一レポート・固定 PT の pull が訓練と評価にリークしないよう分割。
  - パッチ・レベルシンク別に実測ログからダメージ・回復式を較正（FFLogs 被ダメに含まれる防御補正の二重適用を防止）。
  - 評価指標：生存率信頼区間、Party / MT / ST それぞれの最低 HP、MP 枯渇率、復帰直後の攻撃 GCD 損失。
